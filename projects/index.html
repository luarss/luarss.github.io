Projects & Publications

Open source projects and research publications.

I actively contribute to open source projects in AI agents and AI-assisted tools for chip design. My work spans from production AI agent runtimes to MCP servers for developer tooling.

Open Source Projects#

nova-agent-runtime — Python AI agent framework with integrated tools, multi-agent workflows, and evaluation loops. Features native MCP integration, automatic context management, and YAML-based declarative configuration.

openroad-mcp — Python, Tcl MCP server for real-time AI-driven debugging for chip designers in OpenROAD.

ORAssistant — Python, Tcl Production-ready LLM chatbot assistant for the OpenROAD chip design tool. Conceptualised and open-sourced as part of OpenROAD Project contributions.

Publications#

ORAssistant: A Custom RAG-based Conversational Assistant for OpenROAD (WOSET 2024) Paper on a custom RAG-based conversational assistant for chip design automation using OpenROAD.

Extended Tactile Perception: Vibration Sensing through Tools and Grasped Objects (IROS 2021 — Best Paper Award) ML classification models for high-dimensional time-series tactile sensor data enabling vibration sensing through tools and grasped objects.
