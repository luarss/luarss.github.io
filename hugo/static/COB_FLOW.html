Procure-to-Pay Flows

Request for Payment  ·  Request for Approval

1 — Request for Payment

Raise → Approver → Finance Ops → (optional) vendor docs → stage cleared
flowchart TD
    A([Requester raises request]) --> B[Attach quotation]
    B --> C{Approver approves?}
    C -->|No| X([Rejected / returned])
    C -->|Yes| D[Route to Finance Ops]
    D --> E[Finance Ops does manual processing]
    E --> F{Existing vendor bank account on file?
marked by requester}
    F -->|Yes| H([Documents stage cleared])
    F -->|No| G[Route back to requester for documents]
    G --> G1[1 · Vendor creation form]
    G --> G2[2 · Bank account proof]
    G1 --> I[Requester submits documents]
    G2 --> I
    I --> J[Route back to Finance Ops to clear stage]
    J --> H
    H --> K([Proceed to Request for Approval])

2 — Request for Approval

Prereqs met → Finance Office → vendor invoice → OCR amount check → payment platform
flowchart TD
    A([Prerequisites met · all documents in place]) --> B[Finance Ops routes to Finance Office manually]
    B --> C{Finance Office confirmation received?}
    C -->|No| C
    C -->|Yes| D[Prompt vendor to submit invoice]
    D --> E[Vendor submits invoice]
    E --> F["OCR extracts invoice amount
suggested amount shown to Finance Ops only"]
    F --> G{Invoice amount <= quoted / approved amount?
manual check at first}
    G -->|No| H([Reject / query vendor])
    H --> D
    G -->|Yes| I[Route to payment platform]
    I --> J([Automation to be built here])

Assumptions & open points

  • Optional docs branch: "Existing bank account on file = Yes" skips document collection; "No" routes back to the requester for the vendor-creation form + bank-account proof, then returns to Finance Ops to clear the stage.
  • OCR step: initially a manual gate — OCR only suggests the amount, visible to Finance Ops on the frontend; not yet an automated pass/fail.
  • Rejection loops: approver-reject and OCR-mismatch return points are inferred, not fully specified.
  • Payment platform: handoff to the payment board is where the downstream automation will be built.
